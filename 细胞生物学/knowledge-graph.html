学习路线图

第一阶段：基础认知（1-3章）

  • 细胞学说 → 三大核心内容
  • 原核 vs 真核 → 对比表格
  • 病毒 → 非细胞形态生命体
  • 显微镜 → TEM vs SEM
  • 研究方法 → 差速离心、密度梯度离心

第二阶段：结构与功能（4-9、15章）

  • 质膜 → 流动镶嵌模型、物质运输
  • 内膜系统 → ER→高尔基→溶酶体
  • 线粒体/叶绿体 → 氧化磷酸化、内共生
  • 细胞骨架 → 微丝/微管/中间纤维 + 马达蛋白
  • 细胞核 → 核小体、染色体、NLS
  • 核糖体 → 翻译过程、核酶

第三阶段：调控与命运（10-14章）

  • 信号转导 → GPCR、RTK-Ras-MAPK
  • 第二信使 → cAMP、IP₃、Ca²⁺
  • 细胞周期 → G₁/S/G₂/M、有丝vs减数
  • 周期调控 → MPF、检验点、p53、癌基因
  • 细胞分化 → 全能性、干细胞、管家基因
  • 细胞凋亡 → Caspase、凋亡vs坏死

跨章节核心线索

蛋白质的旅程

核糖体合成 → 信号假说 → rER加工 → 高尔基体修饰 → 囊泡运输 → 胞吐/溶酶体/质膜
（第5章 + 第9章 + 第4章）

信号传递链

信号分子 → 受体 → G蛋白/Ras → 第二信使 → 激酶级联 → 基因表达 → 细胞增殖/分化/凋亡
（第10章 + 第12章 + 第13章 + 第14章）

能量与细胞器起源

糖酵解 → 三羧酸循环 → 氧化磷酸化 → ATP → 主动运输/肌肉收缩/信号转导
（第6章 + 第4章 + 第7章 + 第10章）

细胞周期全景

信号刺激 → Cyclin-CDK激活 → 通过检验点 → DNA复制 → 有丝分裂 → 胞质分裂
→ 异常 → p53阻滞 → 修复or凋亡（第11章 + 第12章 + 第14章）
