本章核心地位

绪论是整个生物化学的总纲。它回答三个根本问题：什么是生物化学？生命体由什么构成？生命现象背后的化学逻辑是什么？许多学校的考研题会把绪论与后面各章交叉命题，所以本章内容贯穿始终。

一、生物化学的定义与研究范畴

直觉类比

生物化学就像"生命的化学说明书"——如果把细胞比作一台精密机器，生物化学就是解释这台机器用什么材料造的（结构生物化学）、怎么运转的（代谢生物化学）、信息如何传递复制的（分子生物学）。

1.1 生物化学的定义

生物化学（Biochemistry）是研究生物体内化学分子与化学反应的科学，它以生命为研究对象，以化学为研究手段，在分子水平上阐明生命现象的本质。

考研考点

常考填空题/名词解释：生物化学的核心任务：①阐明生物大分子的结构与功能关系；②阐明生物体内的物质代谢与能量代谢过程；③阐明生物遗传信息的传递与表达调控机制。

1.2 生物化学的主要分支

分支研究对象核心问题
结构生物化学生物分子的化学组成和三维结构"它们是什么？长什么样？"
代谢生物化学细胞内化学反应及其能量转化"它们如何变化？能量怎么来？"
分子生物学遗传信息的储存、传递和表达"信息如何编码、复制、翻译？"

易错辨析

误区：认为"生物化学=分子生物学"。
正解：分子生物学可视为生物化学的一个分支，但更聚焦于核酸和遗传信息流。两者在考试中常常混着考，注意题目用词区分侧重点。

二、生命体的化学特征

动机推演

为什么生命需要如此复杂的化学体系？

生命的本质特征——自我维持、自我复制、自我调控——要求生命体具备：(1)精确的信息编码系统；(2)高效的能量转换机制；(3)严密的自组装能力。这些要求决定了生命必须依赖碳基大分子和水溶液体系。

2.1 生命体的元素组成

组成生命体的主要元素为 C、H、O、N、S、P，这六种元素构成了生命体的 99% 以上。此外还有 Na、K、Ca、Mg、Cl 等大量元素，以及 Fe、Cu、Zn、Mn 等微量元素。

考研考点

选择题高频考点：组成生物体干重最多的元素是C（而非O），因为H₂O不计入干重。按原子数计，H 最多（水分子含2H）。

2.2 碳——生命化学的核心

碳原子因其以下特性成为生命分子的骨架：

  • 四价键合能力：可形成单、双、三键，允许构造极大的结构多样性
  • 键能适中：既稳定（常温保持结构），又可被酶催化断裂
  • 四面体构型：创造了分子的三维空间结构，是分子识别的结构基础

直觉类比

碳原子就像乐高积木中的"通用连接块"——每个碳有四个连接点，可以组成直链、分支链、环状结构，进而拼接出从甲烷到DNA的一切生命分子。

三、生物分子的层次结构

3.1 从原子到生命体的层级体系

原子 → 小分子（氨基酸、核苷酸、单糖、脂肪酸） → 大分子（蛋白质、核酸、多糖、脂类） → 超分子复合物（核糖体、染色质） → 细胞器 → 细胞 → 组织 → 器官 → 生命体

考研考点

简答题常见："试述生物分子的层次结构及其意义"。
关键得分点：①层级递进性；②每级出现新的涌现性质(emergent properties)；③大分子层面是功能核心（酶催化、信息编码、结构支撑）。

3.2 四大类生物大分子对比

类别单体单元连接键主要功能
蛋白质20种氨基酸肽键催化、结构、运输、信号
核酸4种核苷酸3',5'-磷酸二酯键信息储存与传递
多糖单糖糖苷键能量储存、结构支撑
脂类（非聚合物）脂肪酸+甘油等酯键等能量储存、膜结构、信号

易错辨析

误区：脂类不是聚合物，因此不严格符合"大分子=单体聚合"的定义。
正解：脂类虽不是线性聚合物，但其自组装形成的膜结构体现相同原理。考试中"四大类生物分子"常指蛋白质、核酸、多糖和脂类。

四、水与生命

动机推演

生命为什么在水中起源并依赖水？

水提供了：(1)优良溶剂——溶解和运输各种分子；(2)弱相互作用介质——氢键、疏水作用等非共价力（这些力是分子识别的关键引擎）；(3)热缓冲——比热容大，维持温度稳定；(4)反应参与者——水解反应、光合作用中原初反应。

4.1 水的分子特性

  • 强极性：O-H键极性强，O带部分负电、H带部分正电
  • 氢键能力：每个水分子可形成最多4个氢键（2个给体 + 2个受体）
  • 高介电常数：有效屏蔽离子间静电引力，使离子在水中溶解

4.2 水与弱相互作用

生物体系中四种主要的弱相互作用（非共价力）：

类型本质能量范围生物意义
氢键电负性原子间的氢共享12-30 kJ/mol维持蛋白质和DNA结构
疏水相互作用非极性分子聚集避开水依赖疏水表面积蛋白质折叠、膜形成主驱动力
范德华力瞬时偶极间的吸引力0.4-4 kJ/mol分子紧密接触时的互补性
离子键（盐桥）正负电荷间引力20-40 kJ/mol(水中减弱)稳定蛋白质构象

考研考点

高频命题点：

  • "为什么说疏水相互作用不是一种真正的"键"而是熵驱动的过程？"——疏水分子周围水分子形成笼状结构（熵减），疏水分子聚集释放水分子（熵增），因此是熵驱动的自发过程。
  • "为什么水的沸点异常高？"——水的广泛氢键网络。
  • "比较氢键和共价键的异同"——氢键是分子间力，共价键是分子内力；能量相差约10-15倍。

五、生物能量学概要

5.1 热力学基本概念

生物体是开放系统，与外界交换物质和能量。生命维持低熵状态需要持续的能量输入。

  • ΔG（吉布斯自由能变化）：判断反应自发性。ΔG＜0 自发（放能），ΔG＞0 非自发（需能），ΔG=0 平衡
  • ATP：细胞的"能量货币"，水解时释放约-30.5 kJ/mol 的自由能
  • 偶联反应：热力学不利反应与ATP水解偶联，使总ΔG＜0

直觉类比

ATP就像细胞中的"移动电源"——ATP水解释放能量"充电"给需要能量的反应（如蛋白质合成）。用完的"电源"（ADP）再去"充电站"（线粒体/叶绿体）充满回ATP。

5.2 Gibbs自由能与平衡常数

ΔG°' = -RT ln K'eq

其中 R = 8.315 J/(mol·K)，T 为绝对温度(K)，K'eq 为 pH=7 时的平衡常数。

易错辨析

误区：ΔG＜0 的反应一定快。
正解：ΔG 只管热力学自发性，不管动力学速率。氧化葡萄糖 ΔG 很负但室温下自发反应极慢，需要酶催化。温度主要影响反应速率（动力学），ΔG 基本不受影响。

误区：ΔG°'=0 时反应物和产物浓度相等。
正解：ΔG°'=0 时 K'eq=1，即平衡时产物浓度等于反应物浓度，两者相等而非"浓度为零"。

第2章 氨基酸

本章速览：氨基酸是蛋白质的结构单元。掌握20种标准氨基酸的分类与缩写是后续所有章节的基础， 等电点(pI)的计算是高频考题，肽键的化学本质是理解蛋白质三维结构的起点。

2.1 20种标准氨基酸的结构与分类

🔑 直觉类比：如果把蛋白质比作一篇文章，氨基酸就是26个字母——种类有限（20种）， 但排列组合产生无限多样性。三字母缩写像读音提示（如 Gly = glycine），单字母缩写是速记符号。

2.2 氨基酸的手性与等电点

手性：除甘氨酸（R=H，无手性碳）外，所有标准氨基酸的α-碳均为手性中心，天然蛋白质中均为L-构型。 用Fischer投影式表示时，—NH₂在左侧。D-氨基酸存在于细菌细胞壁和某些抗生素中。

等电点 pI：氨基酸净电荷为零时的pH值。对于中性氨基酸（一氨基一羧基）： $$\mathrm{pI = \frac{pK_1 + pK_2}{2}}$$ 对于酸性氨基酸（Asp, Glu）：$\mathrm{pI = \frac{pK_1 + pK_R}{2}}$（取两个较小的pKa） 对于碱性氨基酸（Lys, Arg, His）：$\mathrm{pI = \frac{pK_2 + pK_R}{2}}$（取两个较大的pKa）

🧠 动机推演：为什么酸性氨基酸pI偏酸（~3），而碱性氨基酸pI偏碱（~9-10）？ 因为pI是净电荷为零的pH——酸性氨基酸需要更酸的pH才能让第二个羧基质子化（中和负电荷）， 而碱性氨基酸需要更碱的pH才能让氨基去质子化（中和正电荷）。

2.3 茚三酮反应

原理：茚三酮与α-氨基酸的游离α-氨基反应，生成蓝紫色产物（Ruhemann紫）， 可在570 nm处定量检测。脯氨酸（亚氨基酸）产生黄色产物（440 nm）。

🔑 直觉类比：茚三酮反应就像氨基酸的"指纹显影剂"——只要有游离α-氨基就能显色， 因此蛋白质（N端游离）也能反应，而肽键内部的氨基酸残基则不能。

2.5 肽键的化学本质

肽键：一个氨基酸的α-羧基与另一个氨基酸的α-氨基缩合形成的酰胺键（—CO—NH—）。

📌 关键特征：
① 部分双键性质：肽键中的C—N键具有约40%的双键特性（酰胺共振），键长0.132 nm（介于单键0.147 nm与双键0.127 nm之间），不能自由旋转
② 反式构型：天然蛋白质中绝大多数肽键为反式（trans），因为空间位阻最小。例外：X-Pro肽键约6%为顺式
③ 肽单位（Cα—CO—NH—Cα）的六个原子共面
🧠 动机推演：肽键的部分双键性质是理解蛋白质结构的逻辑起点——正因为肽键不能旋转， 多肽链主链的构象自由度仅由两个可旋转的单键决定：Cα—N键（φ角）和Cα—C键（ψ角）。 这两个二面角的允许取值直接决定了蛋白质的二级结构类型。

第3章 蛋白质的一级结构

3.1 一级结构的定义

蛋白质一级结构：多肽链中氨基酸残基的线性排列顺序（N端→C端），包括二硫键的位置。 一级结构是蛋白质高级结构的基础——氨基酸序列决定了三维折叠方式。Anfinsen实验 （核糖核酸酶变性-复性实验，1972年诺贝尔化学奖）证明了这一原理。

🔑 直觉类比：一级结构就像一篇文章的段落——单词（氨基酸）的顺序决定了句子的意思。 Anfinsen实验相当于把文章揉成一团（变性），展开后发现仍能读回原来意思（复性）——信息完全储存在序列中。

3.2 蛋白质测序方法

Edman降解法（经典方法）：用异硫氰酸苯酯（PITC）与多肽N端α-氨基反应， 在温和酸性条件下将N端氨基酸以PTH-氨基酸形式切下（不破坏其余肽键）， 通过HPLC鉴定PTH-氨基酸种类，循环进行可测定约50个残基序列。

📌 Edman降解三步：
① 偶联：PITC + N端α-NH₂（碱性pH）→ PTC-肽
② 裂解：无水酸条件下，N端氨基酸以ATZ-氨基酸形式选择性裂解
③ 转化：ATZ-氨基酸 → 稳定的PTH-氨基酸 → HPLC鉴定

质谱法（现代主流）：ESI-MS（电喷雾质谱）和MALDI-TOF-MS可用于精确测定肽段质量。 串联质谱（MS/MS）通过碰撞诱导解离（CID）产生b离子和y离子系列，从碎片谱中解析氨基酸序列。

🧠 动机推演：为什么需要两种方法？Edman降解适合从头测序，但速度慢、需要较多样品； 质谱法灵敏度极高（fmol级）、速度快，但依赖数据库匹配。两者互补。

3.3 重要测序历史：胰岛素

Sanger测序胰岛素（1953年，弗雷德里克·桑格——1958年诺贝尔化学奖）： 牛胰岛素由A链（21残基）和B链（30残基）通过两个链间二硫键（A7-B7, A20-B19）和一个链内二硫键（A6-A11）连接。 这是人类确定的第一个蛋白质序列，证明了蛋白质具有确定的氨基酸序列。

Sanger策略：① 用过甲酸氧化断裂二硫键，分离A、B链； ② 用多种蛋白酶（胰蛋白酶、胰凝乳蛋白酶等）分别酶解，得到重叠肽段； ③ Edman降解（当时用DNFB法——Sanger试剂）测定各肽段序列； ④ 通过重叠肽段拼接完整序列。

3.4 同源蛋白质与分子进化

同源蛋白质：不同物种中执行相同功能的蛋白质（如细胞色素c、血红蛋白）， 其氨基酸序列相似程度反映物种间的进化关系。考研高频：比较细胞色素c序列差异→构建分子进化树。

不变残基：对结构和功能至关重要的残基在进化中保持不变（如活性位点残基、形成二硫键的半胱氨酸）。 保守替换：由性质相似的氨基酸替换（如Ile↔Leu↔Val），不影响功能。

🔑 直觉类比：同源蛋白质如同同一故事在不同语言中的版本——句子结构（三级结构）高度保守， 但个别用词（氨基酸）有变化。不变残基就像故事中的主角名字，换了就讲不通了。

第4章 蛋白质的三维结构

本章速览：蛋白质三维结构分为四个层次——二级、超二级、三级、四级。 理解α-螺旋的结构参数（3.6残基/圈、i→i+4氢键）和Ramachandran图是掌握结构生物学的关键。 血红蛋白α₂β₂是四级结构的经典范例。

4.1 二级结构

📌 α-螺旋（α-helix）— 必考
• 右手螺旋，每圈3.6个氨基酸残基，螺距0.54 nm（即每个残基升高0.15 nm）
• 氢键模式：第i个残基的C=O与第i+4个残基的NH形成氢键（i→i+4）
• 所有肽键的C=O和N—H均参与氢键形成（除两端3-4个残基外）
• 侧链R基指向螺旋外侧，避免空间冲突
• φ ≈ −57°, ψ ≈ −47°
• 破坏α-螺旋的残基：脯氨酸（环状结构，无法形成氢键且造成"扭结"）、甘氨酸（太灵活，不利于螺旋稳定）
• 右旋α-螺旋在能量上最稳定
🔑 直觉类比：α-螺旋就像螺旋楼梯——每个台阶（残基）旋转100°， 每走3.6个台阶转完一圈（360°/100° ≈ 3.6）。氢键好比楼梯内侧的扶手，把所有台阶连在一起， 让整个结构稳固。

4.1.2 β-折叠

📌 β-折叠（β-sheet）— 高频
• 多肽链几乎完全伸展，呈锯齿状折叠构象
• 氢键在相邻肽段之间形成（链间氢键，不同于α-螺旋的链内氢键）
• 反平行β-折叠：相邻肽段方向相反，氢键排列整齐，更稳定
• 平行β-折叠：相邻肽段方向相同，氢键排列倾斜，稳定性略低
• 侧链交替伸向折叠面的上方和下方
特性α-螺旋β-折叠
氢键类型链内（i→i+4）链间
每残基升高0.15 nm0.32 nm（反平行）/ 0.34 nm（平行）
侧链取向向外交替上下
破坏因子Pro、Gly、连续带电残基大侧链残基

4.1.3 β-转角与无规卷曲

β-转角（β-turn）：由4个氨基酸残基组成的180°急转弯，第1个残基的C=O与第4个残基的NH形成氢键。 常含有甘氨酸（小而灵活）和脯氨酸（天然弯曲），位于蛋白质表面。

无规卷曲：蛋白质中不规则的环状和卷曲区域，具有特定但非重复的构象。 并非真的"无规"——在同一蛋白质的不同分子中构象相同（由序列编码决定），因此应更准确地称为"环区（loop）"。

4.2 Ramachandran图

📌 核心概念：以φ（Cα—N旋转角）为横轴、ψ（Cα—C旋转角）为纵轴， 标注出蛋白质主链构象的允许区域。大多数非甘氨酸残基的(φ, ψ)角落在三个允许区：
• 右上区：β-折叠构象（φ ≈ −120°, ψ ≈ +120°）
• 左下区：右手α-螺旋构象（φ ≈ −57°, ψ ≈ −47°）
• 左上区：左手α-螺旋构象（较少见）
⚠️ 易错辨析：
① 甘氨酸：侧链仅为H原子，空间位阻极小 → Ramachandran图中允许区域远大于其他残基 → 结构灵活性最高 → 常出现在转角区域
② 脯氨酸：侧链与主链N共价成环 → φ角被固定约 −60° → Ramachandran图中允许区域非常狭窄 → "结构约束者"
🧠 动机推演：为什么需要Ramachandran图？肽键的部分双键性质消除了ω旋转自由度， 理论上每个残基有φ、ψ两个可旋转角。但并非所有(φ, ψ)值都允许——原子间存在空间冲突。 Ramachandran图用最简单的范德华半径计算预测了允许区域，后被大量高分辨率晶体结构验证。 这是理论预测与实验数据完美吻合的经典案例。

4.3 超二级结构与结构域

超二级结构（模体/motif）：若干相邻二级结构单元组合形成的特定几何排列， 如βαβ单元、β-发夹、αα单元、希腊钥匙模体、β-迂回等。 是介于二级结构和结构域之间的结构层次。

结构域（domain）：多肽链中独立折叠的结构单位，通常是连续的一段序列（约100-200残基）， 具有相对独立的疏水核心。由Gilbert于1978年提出。按二级结构组成分为： 全α域、全β域、α/β域（βαβ交替）、α+β域（α和β区域分离）。

4.4 三级结构

三级结构：整条多肽链在空间中折叠形成的完整三维结构。维持三级结构的力包括：

作用力类型特征重要性
疏水作用非极性侧链聚集成疏水核心，释放有序水分子→熵增主要驱动力
氢键主链和侧链间形成稳定二级结构、定向侧链
离子键（盐桥）带相反电荷的侧链间静电吸引表面稳定性
范德华力紧密堆积原子间的弱相互作用数量大，总体贡献显著
二硫键两个Cys的—SH氧化共价交联锁定构象，多见于分泌蛋白
🔑 直觉类比：疏水作用就像油滴入水——非极性侧链"被迫"聚集在内部（疏水核心）， 就像油滴自发聚成球状以最小化与水接触。极性/带电侧链则面向水环境（蛋白质表面）。

4.5 分子伴侣与蛋白质折叠

分子伴侣：辅助蛋白质正确折叠的蛋白质，自身不是最终功能分子的组成部分。 代表：Hsp70（DnaK）、Hsp60（GroEL/GroES）。

GroEL/GroES系统：GroEL为双层七聚体环形桶状结构（内腔为疏水环境），GroES为"盖子"。 错误折叠/未折叠蛋白质进入GroEL内腔→GroES盖住→ATP水解驱动构象变化→内腔变为亲水→蛋白质在此"隔离室"中正确折叠→释放。

4.6 四级结构：血红蛋白 α₂β₂

四级结构：由两条或以上多肽链（亚基）通过非共价相互作用组装形成的寡聚体结构。

📌 血红蛋白（Hb）α₂β₂ — 必考经典
• 4个亚基：2条α链（141残基）+ 2条β链（146残基）
• 每个亚基含一个血红素辅基（Fe²⁺结合O₂）
• 亚基间通过非共价相互作用（疏水作用、氢键、盐桥）紧密结合
• α₁β₁和α₂β₂接触面大而稳定 → αβ二聚体（基本单位）
• α₁β₂和α₂β₁接触面较松，在T态↔R态转变中发生滑动

第5章 蛋白质的功能与进化

本章速览：本章的核心是理解蛋白质功能的分子机制—— 以肌红蛋白/血红蛋白为模型理解氧合曲线和别构效应， 以免疫球蛋白为例理解蛋白质的结构-功能关系， 以镰刀形细胞贫血为例理解单个氨基酸突变如何导致分子病。

5.1 肌红蛋白与血红蛋白的氧合曲线

肌红蛋白（Mb）：单体（153残基），含一个血红素。氧合曲线为双曲线（hyperbolic）， 符合Michaelis-Menten型饱和动力学，P₅₀ ≈ 2.8 torr。

血红蛋白（Hb）：四聚体 α₂β₂，氧合曲线为S形曲线（sigmoidal）， P₅₀ ≈ 26 torr。S形曲线说明O₂结合具有正协同效应——第一个O₂的结合促进后续O₂的结合。

🔑 直觉类比：肌红蛋白像一个小公寓——一个人（O₂）住进去很容易，进出门是双曲线。 血红蛋白像一个四人宿舍——第一个人搬进去把门打开，后面的人就更方便入住（正协同效应，S形曲线）。
特性肌红蛋白 (Mb)血红蛋白 (Hb)
亚基数1（单体）4（α₂β₂四聚体）
氧合曲线双曲线S形（sigmoidal）

5.2 别构效应

📌 正协同效应（Positive Cooperativity）— 必考
• 第一个配体的结合促进后续配体的结合（O₂与Hb的结合）
• 分子机制：第一个O₂结合→血红素Fe²⁺移入卟啉平面→牵拉近端His F8→F螺旋位移→亚基界面重组→其余亚基转变为高亲和力R态
• Hill方程：$\log\frac{Y}{1-Y}=n_H\log p\mathrm{O_2} - \log P_{50}$
• Hill系数 n_H：Mb = 1.0，Hb ≈ 2.8（理论最大4.0）

5.2.2 Bohr效应与2,3-BPG

Bohr效应：H⁺和CO₂促进Hb释放O₂。在活跃代谢的组织中，CO₂↑和H⁺↑（pH↓） → Hb对O₂亲和力降低（P₅₀增大）→ 在组织中释放更多O₂。生理意义：代谢越旺盛的组织越需要O₂，Bohr效应精确实现按需供氧。

📌 分子机制：H⁺与β链C端His146的咪唑基结合→形成与Asp94的盐桥→稳定T态→降低O₂亲和力。 CO₂与N端α-NH₂形成氨基甲酸（carbamate）→产生负电荷→形成盐桥→同样稳定T态。

2,3-BPG（2,3-二磷酸甘油酸）：红细胞中高浓度存在， 结合于Hb四聚体中央空穴（β₁和β₂亚基之间），与β链的三个正电荷残基（Lys82、His2、His143）形成盐桥， 选择性地稳定T态，使Hb的氧合曲线右移（P₅₀增大），促进O₂释放。

⚠️ 易错辨析：
① 2,3-BPG结合的是T态（脱氧Hb），而非R态（氧合Hb）——中央空穴在R态时变小，容纳不下BPG
② 胎儿Hb（HbF，α₂γ₂）：γ链143位为Ser（而非His），减弱与BPG的结合→对O₂亲和力高于成人Hb→有利于从母体获取O₂
③ 考研高频：高海拔适应——红细胞中BPG浓度升高，促进组织获氧

5.4 免疫球蛋白的基本结构

📌 IgG基本结构（Y形分子）

5.5 分子病：镰刀形细胞贫血

📌 镰刀形细胞贫血 — 必考经典
• 病因：HbA β链第6位Glu→Val（单个核苷酸突变：GAG→GTG，A→T颠换）
• 结构后果：Val为疏水残基，在脱氧HbS表面形成一个"黏性疏水补丁"，与另一个HbS分子β链的疏水口袋（Phe85、Leu88）结合→HbS多聚化→形成纤维状沉淀
• 细胞后果：红细胞从双凹圆盘形变为镰刀形→脆性增加→溶血→贫血
• 遗传方式：常染色体隐性遗传（纯合子患病，杂合子为镰刀形细胞性状——有部分保护免于疟疾）
• 历史意义：第一种被阐明分子机制的遗传病（Pauling, 1949年，分子病的概念由此诞生）
🧠 动机推演：Glu与Val的区别——Glu的侧链-COO⁻带负电荷且亲水，Val的侧链-CH(CH₃)₂疏水无电荷。 仅一个残基的变化就导致蛋白质聚合、细胞变形、疾病表型→深刻证明了Anfinsen原理： 序列决定结构，结构决定功能。这是连接基因型与表型的典范。

第6章　核酸的结构与功能

遗传信息如何从上一代传递到下一代？又如何从DNA“翻译”成蛋白质？ 这一切的物理基础就是核酸的分子结构。理解核酸的化学组成与三维结构，是打开分子生物学的第一把钥匙。

6.1 核酸的化学组成

核苷酸 = 碱基 + 戊糖 + 磷酸

核酸（DNA/RNA）是由核苷酸通过3“,5”-磷酸二酯键连接而成的多聚体。 每个核苷酸由三部分组成：

组分DNARNA
碱基A, G, C, TA, G, C, U
戊糖β-D-2“-脱氧核糖β-D-核糖
磷酸磷酸基团磷酸基团

嘌呤（A腺嘌呤、G鸟嘌呤）：双环结构（嘧啶环+咪唑环）。
嘧啶（C胞嘧啶、T胸腺嘧啶、U尿嘧啶）：单环结构。

碱基就像字母表中的字母——只有4种（ATCG或AUCG），但它们的排列组合可以编码整个生物体的全部信息。 这就像二进制只用0和1，却能表达无穷无尽的信息。
易错点1：DNA含T（胸腺嘧啶），RNA含U（尿嘧啶）——T比U多一个5-甲基。
易错点2：核苷 = 碱基+戊糖（去掉磷酸）；核苷酸 = 碱基+戊糖+磷酸。 命名常考：腺嘌呤+核糖 = 腺苷（adenosine）；腺苷+磷酸 = 腺苷酸（AMP）。
易错点3：DNA的戊糖是脱氧核糖（2”位为—H而非—OH），这是DNA比RNA化学稳定性更高的根本原因。

6.2 DNA双螺旋结构（Watson-Crick模型，1953）

A 与 T 之间形成 2 个氢键（A=T）；G 与 C 之间形成 3 个氢键（G≡C）。

因此 GC含量越高，DNA越稳定，Tm值越高。

大沟（Major groove）与小沟（Minor groove）

由于碱基对与糖环的连接方式不对称，双螺旋表面形成宽窄交替的两条沟。

大沟富含碱基特异性信息（氢键供体/受体模式），是蛋白质（转录因子等）识别DNA序列的主要场所。 小沟相对信息贫乏但也可被某些小分子/蛋白质识别。

把双螺旋想象成一条螺旋楼梯：磷酸-糖骨架是两侧的扶手（亲水，朝外）， 碱基对是中间的台阶（疏水，堆叠在内）。大沟和小沟就是扶手外侧宽窄交替的凹槽。

6.3 Chargaff规则

① [A] = [T]，[G] = [C]（在双链DNA中）
② [A] + [G] = [T] + [C]（嘌呤总数 = 嘧啶总数）
③ 不同物种DNA碱基组成不同（物种特异性），但同一物种不同组织相同

这是Watson-Crick提出碱基配对模型的重要实验依据。

6.4 DNA的变性与复性

DNA变性（Denaturation）

在高温、极端pH等条件下，氢键断裂，双链解开成单链。不破坏共价键（磷酸二酯键完好）。

  • 增色效应（Hyperchromic effect）：变性后A260升高约30-40%（碱基从堆叠状态暴露出来）
  • 解链温度 Tm：A260升高达到最大值一半时的温度
  • Tm值与GC含量正相关：G≡C有三个氢键，更稳定。经验公式：Tm ≈ 4(G+C) + 2(A+T)（适用于短片段）
DNA复性（Renaturation / Annealing）

缓慢降温时，互补单链重新配对恢复双螺旋。

  • Cot曲线：以初始浓度(C0) × 时间(t) 为横轴，复性程度为纵轴
  • Cot1/2 值反映基因组复杂度——基因组越大、重复序列越少，复性越慢，Cot1/2越大
易错：变性是“解链”而非“降解”。不要混淆氢键断裂（物理变化，可逆）和磷酸二酯键水解（化学变化，不可逆）。 Tm是“一半解链”时的温度，不是“完全解链”的温度。

6.5 DNA的超螺旋与拓扑异构酶

环状DNA（如细菌染色体、质粒）可形成超螺旋（supercoil）。

  • 负超螺旋：螺旋不足（underwound），有利于DNA复制和转录时局部解链
  • 拓扑异构酶Ⅰ：切断一条链，改变Lk ±1，不需ATP
  • 拓扑异构酶Ⅱ（DNA旋转酶gyrase）：切断两条链，改变Lk ±2，需ATP。在原核生物中引入负超螺旋

7.2 葡萄糖的立体化学

糖的立体化学是考研选择题、判断题的高频考点，尤其是D/L命名法和α/β异头碳的区别。
Fischer投影式 → Haworth透视式 → 椅式构象
  • Fischer投影式：线性表达，竖键朝后，横键朝前
  • D/L 规则：离羰基最远的手性碳（葡萄糖为C5）上的—OH在右边为D，左边为L
  • Haworth透视式：C5上的—OH与羰基加成形成半缩醛环。D型糖的CH2OH在环上方
  • 异头碳（anomeric carbon）：环化后新产生的手性碳C1
  • α-异头体：C1—OH 与 C5—CH2OH 在环的异侧（trans）
  • β-异头体：C1—OH 与 C5—CH2OH 在环的同侧（cis）
  • 变旋现象（mutarotation）：α和β在溶液中通过开链形式互变，比旋光度逐渐变化至平衡值
椅式构象（chair conformation）

吡喃葡萄糖最稳定的构象是椅式，所有大取代基（—OH、—CH2OH）都在平伏键（equatorial）上， 这在β-D-葡萄糖中完美实现——所有—OH都是平伏的，因此β-D-葡萄糖是自然界最丰富的有机化合物。

易错辨析：
① D/L 是构型（configuration），基于Fischer投影式，不能互变；α/β是异头构型，在溶液中可通过开链互变。
② D ≠ d（右旋），L ≠ l（左旋）。D/L是构型标记，d/l是旋光方向，两者没有必然对应关系！
③ 天然氨基酸都是L型，天然单糖几乎都是D型——两者恰好相反，考研常混在一起考。

纤维素（Cellulose）
  • β-1,4糖苷键连接的直链葡萄糖聚合物
  • 链间形成大量氢键，构成坚韧的纤维束（微纤维→纤维素纤维）
  • 人体不能消化纤维素——缺乏纤维素酶（β-1,4-葡聚糖酶）
  • 反刍动物瘤胃中的微生物可产生纤维素酶
淀粉（α-1,4）和纤维素（β-1,4）仅一个糖苷键构型之差（α vs β）， 但α连接使淀粉链弯曲成螺旋（可被淀粉酶识别），β连接使纤维素链笔直伸展形成纤维—— 小小的立体化学差异决定了完全不同的生物学命运。

7.5 糖蛋白与蛋白聚糖

糖蛋白（Glycoprotein）蛋白聚糖（Proteoglycan）
糖含量较少（<50%）很高（可达95%）
糖链结构短链、分支寡糖长链、无分支的GAG（糖胺聚糖）
功能细胞识别、免疫、激素受体结构支撑、润滑（如软骨中的aggrecan）

第8章　脂类与生物膜

水是生命之母，但生命的边界需要用“不溶于水”的材料来构建。 脂类正是这种“水-油边界”的分子基础——它们既能构成分隔内外的屏障，又能保持足够的流动性来维持生命活动。

8.1 脂肪酸

命名与分类
  • 饱和脂肪酸：无双键，如棕榈酸(16:0)、硬脂酸(18:0)
  • 不饱和脂肪酸：含一个或多个双键（天然多为顺式），如油酸(18:1 Δ⁹)
  • ω命名法：从甲基端（ω端）开始编号，ω-3（如α-亚麻酸）、ω-6（如亚油酸、花生四烯酸）
  • 必需脂肪酸：人体不能合成，须从食物获取——亚油酸(18:2 ω-6)和α-亚麻酸(18:3 ω-3)
花生四烯酸(20:4 ω-6)可由亚油酸合成，通常不被归为严格必需脂肪酸，但有些教材也将其列入，注意题干语境。 ω-3（如EPA、DHA）和ω-6脂肪酸在体内有相反的炎症调节作用，ω-3抗炎、ω-6促炎，平衡很重要。

8.2 三酰甘油（Triacylglycerol, TAG）

  • 甘油 + 3分子脂肪酸 → 三酰甘油（酯键连接）
  • 最重要的储能形式——单位质量的储能是糖原的约6倍（疏水、不需水合）
  • 储存在脂肪细胞（adipocyte）的脂滴中，几乎占据整个细胞体积

8.3 膜脂——甘油磷脂与鞘脂

甘油磷脂（Glycerophospholipid）
  • 甘油-3-磷酸为骨架，C1和C2位酯化两分子脂肪酸，磷酸基团上连接极性头部
  • 磷脂酰胆碱（PC，卵磷脂）——头部：胆碱
  • 磷脂酰乙醇胺（PE，脑磷脂）——头部：乙醇胺
  • 磷脂酰丝氨酸（PS）——头部：丝氨酸
  • 两亲性分子：两条脂肪酸尾（疏水）+ 磷酸头部（亲水），是生物膜的基本结构单元
鞘脂（Sphingolipid）
  • 以鞘氨醇（sphingosine）代替甘油为骨架
  • 鞘磷脂：鞘氨醇+脂肪酸+磷酸胆碱，是髓鞘的主要成分
  • 脑苷脂/神经节苷脂：含糖基头部，参与细胞识别

8.4 胆固醇（Cholesterol）

  • 结构：环戊烷多氢菲骨架（四环稠合）+ 异辛基侧链
  • 两亲性：极性—OH（亲水头部）很小，庞大的甾环和侧链（疏水）很大
  • 插入膜磷脂之间，调节膜的流动性——低温阻止磷脂结晶（维持流动），高温限制过度运动（维持刚性）
  • 是所有类固醇激素（性激素、皮质激素）、胆汁酸和维生素D的前体
胆固醇就像细胞膜的“调温器”（buffer）——在天冷时防止膜“冻住”（像防冻剂）， 在天热时防止膜“融化”（像稳定剂），维持膜在最佳流动状态。

8.5 生物膜——流动镶嵌模型（Singer-Nicolson, 1972）

流动镶嵌模型是膜生物学的基石，也是每年必考的核心概念。
模型核心要点
  • 脂双层是膜的“基质”：磷脂形成连续的脂双层，是膜的基本结构
  • 膜蛋白“漂浮”其中：蛋白质像“冰山”一样镶嵌在脂双层“海洋”中
  • 膜是不对称的：内外层脂质组成不同，蛋白质有明确的拓扑方向
  • 膜是流动的：脂质和蛋白质可以在膜平面内自由侧向扩散

8.6 膜脂的运动方式

运动方式描述速度

8.7 膜的相变

  • 相变温度 Tm：从凝胶态（有序）转变为液晶态（流动）的温度

  • 胆固醇使相变变得平缓（消除尖锐的相变点）

第10章 酶学导论

动机推演

为什么生命需要酶？

化学反应需要活化能。没有催化剂时，生物体内绝大多数反应的速率慢到毫无生理意义。酶的进化使得反应速率提升10⁶~10¹⁷倍——这不是小修小补，而是从"不可能"到"瞬间完成"的质变。理解酶的本质，就理解了生命为什么能以化学方式运转。

10.1 酶的定义与化学本质 必考

直觉类比

酶就像细胞内的"专业技师"——每个技师（酶）只擅长一种活（专一性），干活极快（高效性），只在温和条件下工作（常温常压），且工作状态可被调节（可调控性）。没有技师，原料自己反应几乎等于不发生。

酶（enzyme）是由活细胞产生的、具有催化活性的生物大分子。绝大多数酶的化学本质是蛋白质，少数是RNA（核酶，ribozyme）。酶所催化的反应称为酶促反应，被酶作用的物质称为底物（substrate）。

考研考点

  • 填空题/判断题高频：「所有酶都是蛋白质」——错误。核酶的发现（Cech & Altman, 1989年诺贝尔化学奖）证明了RNA也具有催化功能。
  • 名词解释高频：酶、核酶(ribozyme)、底物、酶促反应。

10.2 酶与一般化学催化剂的比较

比较维度酶（生物催化剂）一般化学催化剂
高效性极高——催化效率可达10⁶~10¹⁷倍提升一般——通常10²~10⁴倍提升
专一性极高——对底物和反应类型有严格选择性低——通常对一类反应有效
反应条件温和——常温、常压、近中性pH常需高温、高压、极端pH
可调控性精确——别构调节、共价修饰、酶量调控一般不可调控
化学本质蛋白质（或RNA）无机物或简单有机物

易错辨析

误区：酶只能加快反应，不能改变反应平衡。
正解：这是正确的结论。酶不改变反应的平衡常数(Keq)和ΔG，只降低活化能从而加速达到平衡的过程。考试常以判断/选择题考察这一点。

10.3 酶的活性中心与必需基团 高频

活性中心（active center）是酶分子上直接参与底物结合和催化的一小部分区域，通常由空间上靠近但一级序列上可能远离的若干氨基酸残基组成。

活性中心的基团分为两类：

  • 结合基团——负责识别和结合底物，决定酶的专一性
  • 催化基团——直接参与化学键的断裂和形成，负责催化功能

必需基团（essential groups）是酶发挥催化活性所必需的化学基团，包括活性中心的基团和活性中心以外对维持酶构象必需的基团。必需基团≠全在活性中心。

易错辨析

误区：必需基团就是活性中心的氨基酸残基。
正解：活性中心外的某些残基也是必需基团——它们可能不直接参与催化，但对维持酶的正确三维构象至关重要。化学修饰这些残基一样会导致酶失活。

10.4 酶的专一性 高频

酶的专一性（specificity）是酶区别于一般催化剂的最显著特征。根据严格程度分为：

专一性类型定义实例
绝对专一性只作用于一种底物，催化一种反应脲酶——只水解尿素，不对任何其他酰胺作用
相对专一性（基团专一性）对底物的特定化学基团有要求，对其余部分容忍变化胰蛋白酶——水解Lys或Arg的C端肽键
相对专一性（键专一性）只要求特定的化学键，对键两侧基团容忍度更大酯酶——水解各种酯键
立体专一性区别底物的立体异构体（光学异构或几何异构）L-氨基酸氧化酶只作用于L-氨基酸

直觉类比

专一性就像锁和钥匙——绝对专一性是一把钥匙只开一把锁；基团专一性是一把钥匙能开所有「同一个品牌」的锁；键专一性是一把钥匙能开所有类型的锁，只要锁孔形状一样；立体专一性则是钥匙只能从一个方向插入（左手钥匙打不开右手锁）。

10.5 酶的命名与分类 必考

国际酶学委员会（IEC）将酶按催化反应类型分为六大类：

类别催化反应类型典型例子
1. 氧化还原酶电子转移（氧化还原反应）乳酸脱氢酶(LDH)、细胞色素c氧化酶
2. 转移酶转移功能基团（除H以外）己糖激酶(转移磷酸基)、氨基转移酶
3. 水解酶水解反应（加水断裂化学键）胰蛋白酶、淀粉酶、脂肪酶
4. 裂合酶非水解性地断裂C-C/C-N等键（消除反应）醛缩酶、延胡索酸酶
5. 异构酶催化分子内异构化磷酸己糖异构酶、磷酸丙糖异构酶
6. 连接酶利用ATP的能量连接两个分子DNA连接酶、丙酮酸羧化酶

易错辨析

误区：裂合酶（lyase）与水解酶（hydrolase）都会断裂化学键，分不清。
正解：水解酶加水断裂（如肽键水解），裂合酶不加水，通过消除反应断裂C-C或C-N键并产生双键。简单口诀——「水解酶加水，裂合酶不加水」。

10.6 辅因子：辅酶与辅基 高频

类型与酶的结合方式化学本质实例
辅酶（coenzyme）非共价结合，疏松（可透析除去）小分子有机物NAD⁺、NADP⁺、CoA、FAD
辅基（prosthetic group）共价或极紧密非共价结合，牢固（不可透析除去）有机物或金属离子FAD（有些酶中为共价结合）、血红素、生物素
金属离子可松可紧金属元素Zn²⁺（碳酸酐酶）、Mg²⁺（激酶）、Fe²⁺/Fe³⁺

金属离子的作用：(1) 参与底物结合和定向；(2) 通过静电效应稳定过渡态；(3) 作为亲电催化剂（Lewis酸）；(4) 参与电子传递（氧化还原酶中的Fe、Cu等）。

10.7 酶活力的测定 高频

  • 酶活力单位（IU）：在特定条件下（最适pH、最适温度），每分钟催化转化1 μmol底物所需的酶量。
  • Katal（kat）：国际单位制——每秒催化转化1 mol底物。1 kat = 6×10⁷ IU。
  • 比活力（specific activity）：每毫克蛋白质所含的酶活力单位数（IU/mg或kat/mg）。比活力 = 总活力/总蛋白量，是衡量酶纯度的指标——纯化倍数越高，比活力越大。

10.8 核酶（ribozyme）必考

核酶发现——打破「酶=蛋白质」的教条

1982年，Thomas Cech发现四膜虫（Tetrahymena）的rRNA前体在完全无蛋白质的条件下可以进行自我剪接（self-splicing），证明RNA分子本身具有催化活性。同年，Sidney Altman发现RNase P中的RNA组分才是真正的催化剂。两人共享1989年诺贝尔化学奖。

深远意义：核酶的发现为"RNA世界"假说提供了关键证据——在DNA和蛋白质出现之前，RNA可能同时承担遗传信息存储和催化功能。

第11章 酶动力学 考研重中之重

动机推演

酶动力学的核心问题：速率怎么变？受什么控制？

如果我们知道了v₀与[S]的定量关系，就可以获得Km和Vmax这两个刻画酶特征的关键参数，进而深入理解酶的催化效率和调控机制。抑制剂研究不仅为药物开发提供理论依据（如磺胺类药物），更是考研中区分三种可逆抑制类型的必考点。

11.1 Michaelis-Menten方程的推导前提 必考

M-M方程建立在以下关键假设之上：

  1. 稳态假设（steady-state assumption）：在反应的初始阶段，酶-底物复合物[ES]的浓度保持恒定，即 d[ES]/dt = 0（ES的形成速率 = ES的分解速率）。这是推导的核心前提。
  2. 初始速度条件：[S] >> [E]，[S]几乎不变；[P] ≈ 0，逆反应可忽略。因此只考虑正向初始速度v₀。
  3. 反应模型：$E + S \xrightleftharpoons[k_{-1}]{k_1} ES \xrightarrow{k_{cat}} E + P$

易错辨析

误区：稳态假设等同于平衡假设。
正解：平衡假设要求k₁[E][S] = k₋₁[ES]（即ES仅通过解离回到E+S，不考虑催化步骤）。稳态假设更一般——ES的形成速率 = 分解速率（包括催化和解离两条路径的总和），即k₁[E][S] = (k₋₁ + kcat)[ES]。当kcat << k₋₁时，稳态假设退化为平衡假设。

11.2 M-M方程及其参数 必考

$$v_0 = \frac{V_{\max}[S]}{K_m + [S]}$$

参数定义物理意义单位
Km$\displaystyle\frac{k_{-1}+k_{\mathrm{cat}}}{k_1}$使v₀=Vmax/2时的底物浓度。反映酶与底物的亲和力——Km越小，亲和力越大。当kcat << k₋₁时，Km≈Kd（解离常数）mol/L (M)
Vmax$k_{\mathrm{cat}}[E]_{total}$所有酶分子被底物饱和时的最大速率。与[E]成正比mol·L⁻¹·s⁻¹
kcat催化常数（转换数，turnover number）每个酶分子在饱和条件下每秒转化的底物分子数。kcat = Vmax/[E]totals⁻¹
kcat/Km催化效率/专一性常数综合衡量酶催化效率的最优参数——考虑结合(Km)和催化(kcat)两方面。上限受扩散控制(~10⁸-10⁹ M⁻¹s⁻¹)，达到此上限的酶称为动力学完美酶M⁻¹·s⁻¹

直觉类比

  • Km ≈ 网店对顾客的吸引力——Km越小，说明只需很少底物就能半饱和，酶对底物的亲和力越强。
  • Vmax = 高峰时段的最大处理速度——取决于店员数量([E])和每位店员的速度(kcat)。
  • kcat = 每位店员的单件处理速度。
  • kcat/Km = 综合性价比——既考虑吸引顾客的能力，又考虑处理速度。

11.3 Lineweaver-Burk双倒数作图 必考

将M-M方程取倒数得到线性形式：

$$\frac{1}{v_0} = \left(\frac{K_m}{V_{\max}}\right) \cdot \frac{1}{[S]} + \frac{1}{V_{\max}}$$

以1/v₀为Y轴、1/[S]为X轴作图，得到一条直线：

  • Y截距 = 1/Vmax
  • X截距 = −1/Km
  • 斜率 = Km/Vmax

考研考点

双倒数图是区分三种可逆抑制剂类型的最直观工具。只看直线的交点位置即可判断抑制类型。这是每年必考的内容。

11.5 温度与pH的影响 高频

  • 最适温度：速率随温度先升后降——升温加速分子运动（Arrhenius效应），但过高温度导致蛋白质变性失活。注意：最适温度不是酶的特征常数，随反应时间、底物浓度等条件变化。
  • 最适pH：活性中心关键残基的离子化状态依赖pH——过高或过低pH会破坏活性中心的正确质子化状态。同样，最适pH不是酶的特征常数。

易错辨析

误区：最适温度/最适pH是酶的特征常数。
正解：它们随实验条件（反应时间、缓冲液类型、底物浓度等）而变化，不是酶的特征常数。Km才是酶的特征常数。

11.6 可逆抑制与不可逆抑制

  • 不可逆抑制：抑制剂与酶的必需基团以共价键结合，使酶永久失活。如有机磷农药与丝氨酸蛋白酶活性中心Ser的-OH共价结合。
  • 可逆抑制：抑制剂与酶以非共价键（氢键、疏水作用等）可逆结合，透析或稀释可恢复活性。

11.7 三种可逆抑制的动力学特征 必考——考研核心考点

直觉类比

  • 竞争性：一个冒牌顾客（抑制剂）堵在店门口，真顾客（底物）多了就能挤进去——被饱和时速度不变（Vmax不变），但需要更多顾客才能达到同样的速度（Km增大）。
  • 非竞争性：有人在后门给店员捣乱——不管来多少顾客，捣乱的人让一部分店员永远无法工作，最大处理量降低（Vmax↓），但顾客吸引力不变（Km不变）。
  • 反竞争性：只有顾客进了店、店员正在服务时才有人来捣乱——顾客进来了反而被缠住（Km↓，因为ES被抑制剂"锁住"了使表观亲和力增大），但最大处理速度也下降（Vmax↓）。

磺胺类药物——竞争性抑制的经典范例

磺胺类药物是对氨基苯甲酸（PABA）的结构类似物。细菌需要PABA合成叶酸（二氢叶酸），磺胺竞争性地抑制二氢蝶酸合成酶，阻断叶酸合成→细菌不能合成核酸→抑菌。人类细胞不合成叶酸（从食物获取），因此磺胺对人有选择性毒性。这体现了竞争性抑制的三要素：(1)结构类似物；(2)竞争活性中心；(3)提高底物浓度可逆转抑制。

第12章 酶的作用机制

动机推演

核心问题：酶如何在物理化学层面实现催化的"魔法"？

酶促反应速率可以达到非催化反应的10¹⁷倍——这不是巧合。酶的催化效率来自多种策略的精妙组合：邻近效应、定向效应、酸碱催化、共价催化、金属离子催化，以及最重要的——过渡态稳定化。

12.1 过渡态理论 必考

过渡态是反应物→产物转化路径上能量最高的不稳定状态。酶的催化本质是：酶的活性中心与反应的过渡态具有最高的亲和力，通过稳定过渡态来降低活化能（ΔG‡）。

Deep Principle——过渡态稳定化

酶最稳定结合的不是底物也不是产物，而是过渡态。如果酶与底物结合得过紧（活性中心完美匹配底物构象），反而会增加底物→过渡态变形所需的能量，使活化能升高。因此一个好酶的活性中心不完全匹配底物，而是完美匹配过渡态的几何形状和电荷分布。这就是为什么过渡态类似物往往是酶的极强抑制剂（如脯氨酸消旋酶的吡咯-2-羧酸抑制剂，Ki在pM级）。

12.2 酶降低活化能的主要机制 高频

机制原理效应
邻近效应与定向效应将底物分子以正确的空间取向固定在活性中心，大大增加有效碰撞概率等效于将有效浓度提高10³~10⁵倍
酸碱催化活性中心的氨基酸侧链（His的咪唑基、Asp/Glu的羧基、Lys的氨基等）作为质子供体或受体在近中性pH下实现强酸强碱才能完成的质子转移
共价催化酶与底物形成瞬时的共价中间物（如酰基-酶中间体）将单步高活化能反应拆分为两步低活化能反应
金属离子催化金属离子作为Lewis酸（亲电催化剂）、静电稳定剂或氧化还原中心极化底物化学键使其更易断裂
底物应变（构象变形）酶与底物结合迫使底物采取接近过渡态的扭曲构象降低到达过渡态所需的额外变形能

直觉类比

酶就像一位经验丰富的拆弹专家——(1)把两个线头精确定位对齐（邻近+定向），(2)用专用的酸/碱溶液处理接点（酸碱催化），(3)必要时先接上自己的工具再剪（共价催化），(4)利用金属钳子帮忙夹住（金属催化），(5)把雷管预先扭到快要裂的位置（底物应变）。每一步都是为降低"引爆炸弹"的活化能。

12.3 丝氨酸蛋白酶——催化三联体 必考

丝氨酸蛋白酶家族（胰凝乳蛋白酶、胰蛋白酶、弹性蛋白酶）共享相同的催化三联体（catalytic triad）和两步共价催化机制，是酶催化机制的经典范例。

催化三联体：

  • Asp¹⁰²——-COO⁻通过氢键定向His⁵⁷的咪唑环，提高His的pKa使其成为更好的碱
  • His⁵⁷——咪唑基作为一般酸碱催化剂：第一步从Ser¹⁹⁵接受质子（碱），第二步给离去基团提供质子（酸）
  • Ser¹⁹⁵——被His活化为强亲核试剂Ser-O⁻，直接攻击底物羰基碳

催化机制（两步共价催化）：

  1. 酰化阶段：Ser¹⁹⁵-O⁻亲核攻击底物肽键的羰基碳 → 形成四面体过渡态（氧负离子穴oxyanion hole中Gly和Ser的主链-NH稳定此过渡态） → C端肽段离去 → 形成酰基-酶中间体
  2. 脱酰阶段：水分子进入活性中心 → His⁵⁷从水接受质子 → OH⁻攻击酰基-酶中间体 → 第二次四面体过渡态 → 释放N端肽段 → 酶恢复自由态

考研考点

简答题必考："简述丝氨酸蛋白酶的催化机制"。得分要点：①命名催化三联体和各自角色；②两步机制（酰化+脱酰）；③氧负离子穴的作用；④以胰凝乳蛋白酶、胰蛋白酶、弹性蛋白酶为例说明底物特异性的结构基础（S1口袋不同）。

12.4 溶菌酶 高频

溶菌酶（lysozyme）是第一个被阐明三维结构（Phillips, 1965）和催化机制的酶。催化细菌细胞壁肽聚糖中NAM-NAG间的β-1,4-糖苷键水解。

核心机制：

  • Glu³⁵（pKa ≈ 6.5，非寻常高值）：作为一般酸催化剂，提供质子给糖苷键的O
  • Asp⁵²（pKa ≈ 3.5）：静电稳定糖基正离子过渡态（碳正离子）
  • 底物应变：D糖环被扭曲成半椅式构象——这恰好降低到达过渡态所需的能量

12.5 碳酸酐酶 高频

碳酸酐酶是已知催化效率最高的酶之一，kcat/Km ≈ 10⁸ M⁻¹·s⁻¹，接近扩散控制极限。催化反应：CO₂ + H₂O ⇌ HCO₃⁻ + H⁺。

催化机制：

  • 活性中心Zn²⁺配位一个水分子
  • Zn²⁺的Lewis酸效应将水的pKa从15.7降至~7——在生理pH下产生高浓度OH⁻（极强的亲核试剂）
  • OH⁻攻击CO₂的碳原子形成HCO₃⁻
  • 催化效率极高的原因：活性中心精确构造使得每一步都无"浪费"的能量障碍

第13章 酶的调节 考研重点

动机推演

为什么需要调节？

细胞内同时进行数千种化学反应，必须精确协调。代谢网络需要开关和调速器来响应环境变化和内部需求。酶的调节机制从快（毫秒级，别构调节）到慢（小时级，酶量调节）构成分级调控网络。

13.1 别构调节（Allosteric Regulation）必考

别构酶是代谢调控的核心——效应物（effector）结合在活性中心以外的别构位点，通过构象变化影响催化活性。

别构酶的特征：

  • 多亚基结构（具有四级结构）——单亚基酶不可能有别构效应
  • S形（sigmoidal）v-[S]曲线——而非M-M酶的双曲线。S形曲线反映亚基间的正协同效应（一个亚基结合底物后，通过构象变化使相邻亚基更易结合底物）
  • 反馈抑制（feedback inhibition）——代谢途径的终产物抑制该途径第一个关键酶，防止产物过量积累

直觉类比

S形曲线就像一个无级调速开关——低速段迟钝（需要一定底物浓度才能启动），中速段灵敏（底物微小变化引起速率骤变），高速段饱和。这种特性使酶在生理底物浓度范围内具有"开关式"调控能力，M-M酶的双曲线则做不到这一点。

经典别构酶范例——ATCase：

  • 催化嘧啶生物合成第一步（氨甲酰磷酸 + Asp → N-氨甲酰天冬氨酸）
  • 别构抑制剂：CTP（嘧啶终产物→反馈抑制）
  • 别构激活剂：ATP（嘌呤核苷酸→嘌呤和嘧啶需协调合成）
  • 结构：6催化亚基（2三聚体）+ 6调节亚基（3二聚体），T（紧张态）↔ R（松弛态）转变

  • 胰蛋白酶原 → 胰蛋白酶：肠激酶切除N端六肽 → 构象重排 → 活性中心形成。在胰腺中合成无活性的酶原，到达肠道后才激活，保护胰腺自身不被消化。

13.3 别构调节与共价修饰的级联放大 高频

级联放大——信号转导的核心原理

一个激素分子结合受体 → 激活多个G蛋白 → 每个G蛋白激活一个腺苷酸环化酶 → 产生多个cAMP → 每个cAMP激活一个PKA → PKA磷酸化多个靶酶。总放大倍数可达10⁶~10⁸。这就是为什么pM-nM浓度的激素就能引起巨大的细胞响应。

13.4 同工酶 必考

同工酶（isozyme）：催化相同化学反应但具有不同一级结构、Km值和调控特性的酶。

乳酸脱氢酶（LDH）——最经典的同工酶范例：

  • LDH是四聚体，由H亚基（心肌型）和M亚基（骨骼肌型）以不同比例组合
  • 五种同工酶：LDH₁(H₄)、LDH₂(H₃M)、LDH₃(H₂M₂)、LDH₄(HM₃)、LDH₅(M₄)
  • 催化反应：丙酮酸 + NADH + H⁺ ⇌ 乳酸 + NAD⁺
同工酶亚基组成主要分布组织对丙酮酸Km生理意义
LDH₁H₄心肌、红细胞小（高亲和力）有氧组织——偏好乳酸→丙酮酸方向，被高浓度丙酮酸抑制
LDH₅M₄骨骼肌、肝脏大（低亲和力）糖酵解组织——偏好丙酮酸→乳酸方向，不被高浓度丙酮酸抑制

考研考点

LDH同工酶的临床诊断意义——经常考选择题/简答题：

  • 心肌梗死：心肌细胞坏死释放LDH₁入血 → 血清LDH₁ > LDH₂（正常情况LDH₂ > LDH₁）——这是心梗的诊断指标之一
  • 肝脏疾病：肝细胞损伤 → 血清LDH₅升高
  • 同工酶谱的电泳分离：LDH₁移动最快（最靠近阳极），LDH₅最慢

易错辨析

误区：同工酶就是同一基因编码的不同形式。
正解：同工酶由不同基因编码或由同一基因的不同等位基因编码，具有不同的氨基酸序列。它们不是翻译后修饰产生的不同形式（那是"酶的多种形式"而非严格意义上的同工酶）。

13.5 酶量的调节 高频

在基因表达水平调控酶的合成速率和降解速率——是比别构调节和共价修饰更慢但更持久的调控方式。典型例子：

  • 乳糖操纵子：乳糖诱导β-半乳糖苷酶的合成（底物诱导）
  • 胆固醇反馈抑制HMG-CoA还原酶的合成（终产物抑制酶基因表达）
  • 激素（如糖皮质激素）诱导糖异生关键酶PEPCK的合成

第14章 激素与信号转导 必考

核心问题：多细胞生物中，一个细胞如何告诉另一个细胞该做什么？远处的信号如何被精确接收、放大并转化为特定的细胞响应？

14.1 激素的定义与分类 必考

激素（Hormone）是由内分泌腺或特定细胞分泌的、经血液循环运送到靶组织、在极低浓度（nM-pM）下即可发挥调节作用的化学信使。激素不直接参与代谢反应，而是作为「信号」调控细胞已有的代谢程序。

直觉类比：激素好比城市的广播系统——市长办公室（内分泌腺）不需要亲自跑到每家每户，只需要通过广播（血液循环）发布指令，有收音机（受体）的家庭（靶细胞）才能接收并执行。

动机推演：为什么进化出了激素系统？单细胞生物直接与环境交换物质，不需要通讯系统。多细胞生物的细胞需要分工协作，但细胞之间不能物理连接——激素解决了「远距离协调」的问题。从进化上看，激素系统比神经系统更古老（植物只有激素系统），也更能维持长时程响应。

14.2 信号转导的基本模式 重点

信号转导（Signal Transduction）是指细胞将胞外信号分子（第一信使）携带的信息转化为胞内信号（第二信使），并逐级放大，最终引起特定细胞响应的全过程。

信号转导三阶段：接收（Reception） → 转导（Transduction） → 响应（Response）

  • 接收：第一信使（配体）与受体的特异性结合。受体-配体结合服从可饱和性、高亲和力和特异性——类似酶-底物结合。
  • 转导：受体构象变化→激活下游效应器→产生第二信使→信号逐级放大。一级放大可达10⁴-10⁶倍——这就是为什么极低浓度的激素能引起显著的细胞响应。
  • 响应：最终效应包括酶活性改变（快速）、基因表达改变（慢速）、细胞骨架重排、细胞分裂/分化/凋亡等。

信号转导的共同特征：(1) 特异性（特定的受体识别特定的配体）；(2) 放大（酶级联，每个催化步骤放大信号）；(3) 模块化（不同通路共享组件，如cAMP、Ca²⁺被多种信号使用）；(4) 交叉对话（cross-talk，不同信号通路之间相互影响）；(5) 去敏感/适应（持续刺激下响应减弱，防止过度反应）。

14.3 G蛋白偶联受体（GPCR）信号通路 必考

GPCR超家族是人类基因组中最大的受体家族（~800个成员），具有7次跨膜α螺旋的共同结构。其命名源自与异三聚体G蛋白的偶联。约34%的FDA批准药物以GPCR为靶点——足见其在药理学中的核心地位。

14.3.1 异三聚体G蛋白的激活/失活循环 必考

G蛋白分子开关的GTP/GDP循环（核心机制）：

静息态：Gα·GDP + Gβγ 三聚体（Gα与GDP结合，信号关闭）

↓ 配体结合GPCR → 受体构象变化 → 促进Gα释放GDP

激活态：Gα·GTP（Gα与GTP结合后与Gβγ解离）

↓ Gα·GTP 和 Gβγ 各自激活下游效应器

终止：Gα的固有GTP酶活性 → GTP水解为GDP

复归：Gα·GDP 重新与 Gβγ 结合 → 回到静息态

直觉类比：G蛋白像一个「定时炸弹」——静息时Gα绑着GDP（安全栓插着），GPCR激活后拔出GDP换上GTP（拔安全栓，倒计时开始），Gα·GTP和Gβγ各自扩散去激活下游（炸弹分开行动），Gα的GTP酶就是内置的「自动拆弹器」（GTP→GDP，定时归零后自动安全）。

G蛋白类型下游效应器第二信使效应
Gαs激活腺苷酸环化酶(AC)cAMP ↑激活PKA
Gαi抑制腺苷酸环化酶cAMP ↓抑制PKA
Gαq激活磷脂酶C(PLC)IP₃↑ + DAG↑释放Ca²⁺ + 激活PKC
易错：霍乱毒素催化Gαs的ADP-核糖基化，抑制其GTP酶活性 → Gαs·GTP持续激活 → cAMP持续升高 → 肠道上皮细胞大量分泌Cl⁻和水 → 严重腹泻。而百日咳毒素催化Gαi的ADP-核糖基化，阻止Gαi被受体激活 → Gαi无法抑制AC → cAMP升高。两者的靶点不同，但都导致cAMP异常。

14.3.2 cAMP信号通路 必考

cAMP通路主线：

配体(如肾上腺素) → GPCR → Gαs·GTP → 腺苷酸环化酶(AC) → ATP→cAMP → PKA → 磷酸化靶蛋白(如糖原磷酸化酶激酶)

cAMP（3',5'-环腺苷酸）由ATP经腺苷酸环化酶催化生成，被磷酸二酯酶(PDE)水解为5'-AMP而失活。咖啡因和茶碱通过抑制PDE而延长cAMP信号——这就是为什么喝咖啡能提神（之一）。

PKA（cAMP依赖的蛋白激酶A）：静息时PKA是四聚体(R₂C₂)——两个调节亚基(R)抑制两个催化亚基(C)。cAMP与R亚基结合 → R亚基构象变化 → R₂C₂解离 → C亚基释放并磷酸化底物。这是一个别构激活的经典案例。

信号放大级联：1个肾上腺素分子 → 激活1个GPCR → 激活多个Gαs → 每个激活1个AC产生多个cAMP → 激活多个PKA → 每个PKA磷酸化多个底物酶 → 每个底物酶催化多个底物分子。总放大倍数可达10⁶以上。

14.3.3 IP₃/DAG双信使通路 必考

IP₃/DAG通路主线：

配体 → GPCR → Gαq·GTP → 磷脂酶C(PLC) → PIP₂ → IP₃ + DAG

IP₃分支：IP₃ → 内质网膜IP₃受体(Ca²⁺通道) → Ca²⁺释放至胞质 → Ca²⁺/钙调蛋白 → CaM激酶等

DAG分支：DAG + Ca²⁺ → 激活蛋白激酶C(PKC) → 磷酸化靶蛋白

直觉类比：PIP₂好比一个压缩包，PLC把它解压成两个文件——IP₃是「打开钙库的钥匙」（水溶性，扩散到ER），DAG是「留在膜上的PKC激活器」（脂溶性，锚定在质膜内层）。两个信使分工协作，一条信号通路拆成两个并行分支执行。

14.4 受体酪氨酸激酶（RTK）通路 高频

RTK是单次跨膜受体，其胞内域具有酪氨酸激酶活性。代表：胰岛素受体、EGF受体、PDGF受体等。

RTK → Ras → MAPK级联（核心路径）：

1. 配体诱导二聚化：配体结合 → 受体二聚化（或构象变化激活预先存在的二聚体）

2. 自磷酸化：二聚体胞内域互相对方酪氨酸残基磷酸化(trans-autophosphorylation)

3. 接头蛋白招募：Grb2的SH2结构域识别磷酸化酪氨酸，SH3结构域结合SOS

4. Ras激活：SOS是Ras的GEF（鸟苷酸交换因子），促进Ras释放GDP结合GTP

5. MAPK级联：Ras·GTP → Raf(MAPKKK) → MEK(MAPKK) → ERK(MAPK)

6. 效应：ERK进入核内 → 磷酸化转录因子(如Elk-1) → 调控基因表达（细胞增殖/分化）

易错辨析：(1) RTK的二聚化是「配体诱导的」——不同于GPCR（GPCR本身就是单体且有7次跨膜）；(2) 自磷酸化是「trans-」（互相磷酸化），不是「cis-」（自己磷酸自己）；(3) Ras和Gα虽然都是GTP酶，但Ras是小G蛋白（单体~21kDa），Gα是异三聚体G蛋白的一部分——两者都属于GTP酶超家族，但调控机制不同。Ras需要GAP(GTP酶激活蛋白)来加速GTP水解，而Gα自身就有较高的固有GTP酶活性。

14.6 脂溶性激素的作用机制 高频

核受体超家族：脂溶性激素穿越质膜后，与胞内受体（大多位于核内，少数在胞质）结合。激素-受体复合物作为配体激活的转录因子，直接与DNA上的激素响应元件(HRE)结合，调控靶基因的转录。

经典途径：类固醇激素(如皮质醇) → 穿越质膜 → 与胞质中的糖皮质激素受体(GR)结合 → GR构象变化，Hsp90解离 → GR-激素复合物二聚化 → 入核 → 结合DNA上的GRE(糖皮质激素响应元件) → 激活/抑制靶基因转录。

为什么脂溶性激素不需要第二信使？因为它们能直接进入细胞、直接作用于DNA——信号就是激素本身。响应慢（>30分钟才有mRNA变化），但持久（一次激素脉冲可维持数小时到数天的效应）。

14.7 信号转导的终止机制 重点

信号必须终止，否则细胞永远处于「被刺激」状态。

  • 配体清除：激素被降解或重摄取（如神经递质被突触前末梢重摄取）
  • 受体脱敏：GRK(GPCR激酶)磷酸化激活的GPCR → β-arrestin结合 → 阻止G蛋白偶联 + 促进受体内吞 → 受体下调
  • GTP水解：Gα·GTP → Gα·GDP（Gα固有GTP酶活性 + GAP辅助）——这是GPCR信号终止的最基本机制
  • 第二信使降解：cAMP→PDE水解为5'-AMP；IP₃→磷酸酶去磷酸化；DAG→脂酶水解；Ca²⁺→泵回ER/泵出胞外
  • 磷酸酶：蛋白磷酸酶(PP1, PP2A等)去磷酸化被PKA/PKC/ERK等磷酸化的靶蛋白，恢复基态

第15章 生物膜与物质运输 必考

核心问题：细胞如何用一张几纳米厚的脂双层，精确地控制哪些物质能进来、哪些物质必须留在外面？

15.1 生物膜的组成与结构

生物膜的基本结构是脂双层（lipid bilayer），由两亲性磷脂分子自组装形成——亲水头部朝外接触水环境，疏水尾部埋藏在膜内部形成疏水屏障。膜蛋白镶嵌其中（流动镶嵌模型，Singer-Nicolson, 1972）。

组分比例功能
磷脂~40%构成膜的基本屏障——磷脂酰胆碱(PC)、磷脂酰乙醇胺(PE)、磷脂酰丝氨酸(PS)、鞘磷脂(SM)等
胆固醇~20%（动物细胞）调节膜流动性（高温时限制运动、低温时阻止结晶）——「膜流动性的缓冲剂」
膜蛋白~40-50%运输(通道/载体/泵)、信号转导(受体)、催化(酶)、附着(锚定蛋白)
糖类~2-10%糖萼(glycocalyx)——细胞识别、保护、润滑
易错：膜的不对称性——磷脂酰丝氨酸(PS)几乎全部分布在内层（细胞质侧）。当细胞凋亡时PS外翻到外层，成为巨噬细胞识别和吞噬的「吃我」信号。PC和鞘磷脂则主要在外层。

  • 协助扩散= 有闸门的滑道（需要专门的通道/载体，但仍是下坡，不需要能量）

  • 次级主动运输= 一辆下坡的卡车带动另一辆上坡车（利用Na⁺顺梯度的能量来驱动葡萄糖逆梯度运输）

15.3 离子通道的特征 重点

离子通道是跨膜蛋白形成的亲水孔道，允许特定离子快速通过（10⁶-10⁸ ions/s，比载体蛋白快~1000倍）。

三大特征：

  • 选择性（Selectivity）：通道的「选择过滤器」(selectivity filter)仅允许特定离子通过。例如K⁺通道的选择过滤器由保守序列TVGYG的羰基氧原子排列而成，刚好匹配脱水的K⁺（离子半径1.33Å），而Na⁺（半径0.95Å）太小，羰基氧不能有效配位，脱水的能量代价太高。这就是K⁺通道对K⁺的选择性比Na⁺高~10000倍的原因。
  • 门控性（Gating）：通道在开(open)和关(closed)状态之间切换——电压门控（膜电位变化，如Na⁺/K⁺/Ca²⁺通道）、配体门控（配体结合，如乙酰胆碱受体/离子通道）、机械门控（膜张力变化，如听觉毛细胞的机械敏感通道）。
  • 快速性：通道不经过构象变化的催化循环，仅「开/关」切换，转运速率极高。

15.4 Na⁺-K⁺ ATP酶（P型ATP酶）必考

Na⁺-K⁺ ATP酶存在于几乎所有动物细胞质膜上，是维持细胞内外Na⁺/K⁺浓度梯度的核心泵。

化学计量比（必须牢记！）：

每水解1分子ATP → 泵出3个Na⁺ + 泵入2个K⁺

→ 每个循环净移出1个正电荷（生电性泵）

→ 消耗神经元可用ATP的~70%（大脑是高能耗器官）

工作机制（E1-E2模型）：

步骤状态事件
1E1·ATP3个胞内Na⁺结合（高亲和力Na⁺位点）→ ATP水解 → 天冬氨酸残基被磷酸化（形成E1~P）
2E2~P构象从E1变为E2 → Na⁺结合位点亲和力降低，3Na⁺释放到胞外
3E2~P2个胞外K⁺结合（高亲和力K⁺位点）
4E1天冬氨酰磷酸去磷酸化 → 构象从E2变回E1 → K⁺亲和力降低，2K⁺释放到胞内 → 回到步骤1

哇巴因（ouabain）是Na⁺-K⁺ ATP酶的特异性抑制剂，结合在E2~P状态，阻断去磷酸化步骤。洋地黄类药物（地高辛）也是通过抑制心肌细胞Na⁺-K⁺ ATP酶 → 胞内Na⁺↑ → Na⁺/Ca²⁺交换减少 → 胞内Ca²⁺↑ → 心肌收缩力增强（正性肌力作用）。

第16章 生物能学 必考

核心问题：生物化学反应哪些能自发进行？哪些不能？细胞如何利用ATP的能量来「支付」不利反应的热力学代价？

16.1 热力学基本概念复习 必考

Gibbs自由能(ΔG)是判断反应能否在恒温恒压下自发进行的标准：ΔG = ΔH - TΔS。ΔG < 0 自发（放能），ΔG > 0 非自发（吸能），ΔG = 0 平衡。

ΔG°' 与 ΔG 的区别（高频考点）：

ΔG°'（标准生化自由能变化）ΔG（实际自由能变化）
条件pH 7, 25°C, 各物质浓度1M（水55.5M, [H⁺]=10⁻⁷M）细胞内实际浓度（远非1M）
公式ΔG°' = -RT ln K'eqΔG = ΔG°' + RT ln Q（Q为实际反应商）
决定因素仅取决于反应物和产物的化学本质取决于ΔG°' + 实际浓度比

关键公式：$$\Delta G = \Delta G^{\circ\prime} + RT \ln\frac{[\text{产物}]}{[\text{反应物}]}$$

在平衡时，ΔG = 0，Q = K'eq，所以：$$\Delta G^{\circ\prime} = -RT \ln K'_{eq}$$

直觉理解：ΔG°'告诉你的是「在标准条件下反应往哪边走」（反应的固有倾向），ΔG告诉你的是「在当前细胞条件下反应往哪边走」。由于细胞中实际浓度比率可以极低（如产物立即被消耗），一个ΔG°'为+的反应在细胞内仍可能ΔG < 0 从而自发进行。

16.2 ATP——细胞的能量货币 必考

16.2.1 ATP的结构与高能磷酸键的本质

ATP = 腺苷-三磷酸：腺嘌呤碱基 + 核糖（β-N-糖苷键）+ 三个串联的磷酸基团（α-β-γ）。γ和β之间的磷酸酐键即「高能磷酸键」（符号~P）。

「高能磷酸键」为什么「高能」？——这不是因为键能特别高（磷酸酐键的键能本身并不大），而是因为ATP的水解产物（ADP + Pi）比ATP本身稳定得多：

  • 静电排斥减轻：ATP带有4个负电荷（在pH 7时三个磷酸基团负电荷集中），强的静电排斥力使ATP不稳定。水解掉一个磷酸基团，ADP只剩3个负电荷，Pi单独游离，排斥力大幅减小。
  • 共振稳定化：游离Pi比ATP中被连接的磷酸基团有更多的共振形式——Pi可以写出多种等价共振结构，而在ATP中磷酸基团的电子被锁定在P-O键中，共振自由度受限。
  • 电离和溶剂化：ATP水解产生的ADP和Pi能更好地被水分子水合，释放水合能。

动机推演——为什么ATP在中间？如果ATP的ΔG°'太高（如PEP），则ADP磷酸化为ATP会过于困难（因为没有足够能量的供体来驱动此反应）；如果ATP的ΔG°'太低，则ATP水解无法为大多数反应提供足够的驱动力。ATP恰好处于中间位置——它既能被分解代谢（如糖酵解）轻松合成，又能为合成代谢（如蛋白质合成）提供足够的能量。这是进化优化出的完美折中。

16.3 偶联反应原理 必考

偶联反应：将一个热力学不利的反应（ΔG₁ > 0）与一个热力学有利的反应（ΔG₂ << 0，通常是ATP水解）通过共同的中间体偶联，使总反应的ΔG = ΔG₁ + ΔG₂ < 0。

经典实例：葡萄糖 + Pi → 葡萄糖-6-磷酸 + H₂O（ΔG°' = +13.8 kJ/mol，不利）不能直接发生。但将ATP水解偶联：

ATP + H₂O → ADP + Pi（ΔG°' = -30.5 kJ/mol）

葡萄糖 + ATP → 葡萄糖-6-磷酸 + ADP（ΔG°' = 13.8 + (-30.5) = -16.7 kJ/mol）

总反应由己糖激酶催化，磷酸基团直接由ATP转移到葡萄糖——不是先水解ATP再磷酸化葡萄糖，而是通过「磷酸基团转移」机制实现偶联。

易错辨析：偶联不是「ATP先水解产生能量，再用这个能量推动另一反应」——这在化学上说不通，因为热是弥散的，不能定向使用。真正的偶联机制是「形成共同的化学中间体」——ATP的γ-磷酸基团直接转移到葡萄糖上，使得两个反应变成同一个反应序列。

16.4 能荷（Energy Charge）必考

$$\text{能荷(EC)} = \frac{[\text{ATP}] + 0.5[\text{ADP}]}{[\text{ATP}] + [\text{ADP}] + [\text{AMP}]}$$

能荷是细胞内高能磷酸键可用性的度量，反映了腺苷酸池中磷酸酐键的比例。EC的范围是0～1：EC=0表示全是AMP（能量完全耗尽），EC=1表示全是ATP（能量完全充满）。正常细胞EC维持在0.85-0.90的窄范围内。

动机推演：EC同时调控分解代谢和合成代谢——EC低时激活分解代谢（产生ATP）并抑制合成代谢；EC高时激活合成代谢（消耗ATP）并抑制分解代谢。这是一个精细的反馈控制系统，保证细胞能量供应的稳态。关键调控酶（如磷酸果糖激酶、丙酮酸激酶、柠檬酸合酶等）的活性都受EC的别构调节。

17.3 电子传递顺序的确定 高频

  • 各组分氧化还原电位的测定：E°'值从低到高排列——电子自发从低电位流向高电位。NADH/NAD⁺(-0.32V) → FMN(-0.30V) → Fe-S → CoQ(+0.06V) → Cyt b(+0.07V) → Cyt c1(+0.22V) → Cyt c(+0.25V) → Cyt a(+0.29V) → Cyt a₃(+0.55V) → O₂/H₂O(+0.82V)

17.5 氧化磷酸化——化学渗透假说 必考

Peter Mitchell的化学渗透假说（1961年提出，1978年诺贝尔化学奖）：电子传递释放的能量用于将H⁺从线粒体基质泵到膜间隙，在线粒体内膜两侧建立质子电化学梯度（质子动力ΔμH⁺），H⁺经ATP合酶回流时驱动ATP合成。其核心思想是「电子传递与ATP合成通过跨膜H⁺梯度间接耦合」，而非通过「高能化学中间体」。

化学渗透假说的三要素：

1. 线粒体内膜对H⁺不通透（前提——否则H⁺会漏回去）

2. 电子传递→H⁺泵出内膜→质子梯度（ΔpH + Δψ = ΔμH⁺）

3. H⁺只能通过ATP合酶回流→驱动ATP合成

关键实验证据：(1) 解偶联剂(DNP)消除质子梯度，电子传递继续但ATP不合成——证明电子传递和ATP合成是可分离的过程；(2) 人工构建的H⁺梯度可以在没有电子传递的情况下驱动ATP合成；(3) ATP合酶F₀F₁的结构直接证实了质子通道的存在。

17.6 ATP合酶的结构 高频

ATP合酶（F₀F₁-ATPase）是一种精妙的分子马达：

  • F₁（催化头部，基质侧）：由α₃β₃γδε亚基组成。三对αβ交替排列形成六聚体环，β亚基是催化亚基。γ亚基是不对称的中心轴，旋转时依次接触三个β亚基，诱导其构象循环：开放(O)→松散(L)→紧密(T)→开放(O)。T态合成ATP，O态释放ATP。
  • F₀（质子通道，跨膜部分）：由a亚基和c亚基环(c₈₋₁₅)组成。每个c亚基含一个关键Asp/Glu残基。H⁺通过F₀流入→c环旋转→带动γ轴旋转→F₁构象变化→ATP合成。

直觉类比：F₀F₁好比一个水力发电机组——水流（H⁺回流）推动水轮机旋转（c环），旋转的水轮机带动发电机转子（γ轴），转子在定子（α₃β₃）中旋转产生电力（ATP）。这是一个物理旋转与化学合成的精妙耦合——结合改变机制（binding change mechanism）。

17.7 P/O比与解偶联 重点

P/O比：每消耗1个氧原子(½ O₂)所酯化的无机磷酸(Pi)的摩尔数，即产生的ATP分子数。现代测量：

  • NADH → 约2.5 ATP（10个H⁺泵出 ÷ 4个H⁺/ATP ≈ 2.5）
  • FADH₂ → 约1.5 ATP（6个H⁺泵出 ÷ 4个H⁺/ATP ≈ 1.5）

解偶联剂：消除质子梯度而不抑制电子传递的物质。2,4-二硝基苯酚(DNP)是质子载体——在膜间隙侧结合H⁺，扩散到基质侧释放H⁺，短路了ATP合酶。结果是电子传递照常进行，但能量全部以热的形式释放（ATP不合成）。

生理性解偶联：褐色脂肪组织中的解偶联蛋白UCP1（thermogenin）——在线粒体内膜上形成H⁺通道，将质子梯度直接以热的形式释放，用于维持新生儿和冬眠动物的体温。

18.5 水的光解（放氧复合体OEC）高频

OEC（Oxygen-Evolving Complex）位于PSII的类囊体腔侧，核心是一个Mn₄CaO₅簇。通过积累4个正电荷的S态循环(S₀→S₁→S₂→S₃→S₄→S₀)，分5步将2个H₂O分子氧化为1个O₂：

$$2\text{H}_2\text{O} \rightarrow \text{O}_2 + 4\text{H}^+ + 4e^-$$

每次吸收一个光子放出一个电子，累积4个光子后才能一次释放O₂——这是自然界唯一能催化水氧化的生物催化剂。PSII每次被激发，P680⁺从OEC中抽取1个电子（经TyrZ桥接）。

18.6 光合磷酸化 重点

非循环式光合磷酸化：电子从H₂O→PSII→PQ→Cyt b₆f→PC→PSI→Fd→NADP⁺（终点），同时产生ATP和NADPH。H⁺在PSII水光解（腔内）和PQH₂氧化（经Q循环，相似于呼吸链复合体III）时泵入类囊体腔→质子梯度经CF₀CF₁-ATP合酶驱动ATP合成。

循环式光合磷酸化：电子绕PSI循环——Fd→Cyt b₆f→PC→PSI→Fd，仅产生ATP（不产生NADPH，不放O₂）。当细胞需要更多ATP（Calvin循环ATP:NADPH=1.5:1，非循环式产生比例约1.28:1，需要循环式补充ATP）。

18.7 Calvin循环三阶段 必考

Calvin循环（3次循环净合成1分子G3P）：

$$3\text{CO}_2 + 9\text{ATP} + 6\text{NADPH} \rightarrow \text{G3P} + 9\text{ADP} + 8\text{Pi} + 6\text{NADP}^+$$

阶段反应关键酶
1. 羧化CO₂ + RuBP(5C) → 2×3-PGA(3C)RuBisCO（地球上最丰富的酶）
2. 还原3-PGA → 1,3-BPG(ATP) → G3P(NADPH)磷酸甘油酸激酶 + G3P脱氢酶
3. 再生5×G3P → 3×RuBP(5C)（复杂碳骨架重排）转酮酶 + 转醛酶 + 磷酸核酮糖激酶等

Calvin循环的关键数字：3轮循环固定3CO₂ → 产生6分子3-PGA → 还原为6分子G3P → 1分子G3P输出（净合成）→ 5分子G3P再生为3分子RuBP。每净合成1分子G3P消耗9ATP+6NADPH。

易错辨析：Calvin循环的还原阶段与糖酵解的逆过程不同！G3P脱氢酶催化的反应在Calvin循环中使用NADPH（而非NADH），且是从1,3-BPG还原为G3P（合成方向），而糖酵解中是从G3P氧化为1,3-BPG。

18.8 C3与C4植物的比较 高频

光呼吸：RuBisCO不仅能羧化RuBP（正常Calvin循环），还能加氧RuBP（光呼吸——消耗O₂释放CO₂，浪费能量）。C3植物在高温干旱条件下（气孔关闭→O₂/CO₂比例↑）光呼吸严重，显著降低光合效率。

C4植物的适应性：

特征C3植物C4植物

直觉类比：C4途径好比一个「CO₂泵」——PEP羧化酶对CO₂的亲和力远高于RuBisCO（且不加氧），先在叶肉细胞捕获CO₂并浓缩，然后运到维管束鞘细胞「卸货」。这样维管束鞘细胞中的RuBisCO面对高浓度CO₂，加氧活性被抑制，光呼吸大幅降低。
